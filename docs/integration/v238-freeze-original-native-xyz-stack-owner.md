# V238 — Freeze original native X/Y/Z three-axis stack owner

Freeze's original implementation checked actual module epoch, horizontal/vertical settings and opt-in ClickGUI pause after the mapped native X, Y and Z velocity getters and after X/Y setters. It lacked a genuine original-player-pinned reentrant native stack owner. A mapped getter or setter can invoke the movement host before the original X/Y/Z transaction completes. In particular, a nested callback with a DIFFERENT original player or newly focused GUI under enabled pause policy could otherwise leave the old callback permitted to write stale Y/Z after original X or Y.

V238 adds `nativeMotionDispatching`, original `nativeMotionPlayer` pinning and irrevocable `nativeMotionRevoked` across the complete mapped X getter/setter -> Y getter/setter -> Z getter/setter pipeline. Same-player nested callbacks never duplicate a native write, and another player / disabled module / original ClickGUI under enabled pause policy revokes the outer transaction. Existing `nativeReadOwned` checks now combine revocation, actual ON/OFF epoch, horizontal/vertical switches and GUI-pause snapshot after every original getter and X/Y setter. When the native X setter sees source invalidation, actual Y/Z are left alone; when Y setter invalidates the source, actual Z is left alone. A source setter that modifies vanilla motion and then throws is not rolled back.

Preserve the legacy default that Freeze can continue while ClickGUI is open if GUI pause is **disabled**. Also retain independent horizontal and vertical axes, active() yielding to lower-priority owners when both are disabled, 0.0 native motion normalization (including signed -0.0), unknown input neutrality and existing priority masking when GUI pause is opted in.

New original-shaped Java 8/JUnit adapter tests cover mapped getter and setter reentry for X, Y and Z, original-player changes, source GUI focus and default/no-pause behavior, setting and OFF/ON edits, and real partial setter exception recovery. Adapter tests alone do not prove Mojang native gameplay. Exact-head Foundation Windows/Ubuntu, full genuine pinned Minecraft 1.8.9 graphical X11 + vanilla dedicated-server 78-step suite, and independent unchanged-SHA original repeat required. Cumulative Draft child V237, `main` unchanged.
