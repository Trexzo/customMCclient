# V247 — Atomic original local-player XYZ position and speed evidence

`Minecraft189HostRuntime.playerPosition` previously read native mapped `EntityPlayerSP.posX`, `posY`, and `posZ` as three separate getter calls and published the results to `Minecraft189PlayerPositionState` and `Minecraft189MovementSpeedTracker` without one source ownership boundary. A native getter can synchronously invoke this host with a replacement original player or null world-unload source. The earlier player could then publish a mixed or outdated XYZ vector and an incorrect horizontal speed against an old position reference, affecting Movement, target selection and HUD measurements.

V247 introduces `Minecraft189PositionHostSourceLease` pinned to exactly one original `Minecraft189PlayerPositionAccess` across the three original getters. A nested same-player host call is not a new tick. A different/null original source irrevocably revokes the outer sample. Ownership is rechecked after each genuine mapped X, Y and Z read; only a complete same-source XYZ sample gets published and passed to the speed tracker. On owner revocation, original null source or any native getter/finite-validation exception, clear shared player position, peak/current speed and dependent target-rotation source rather than retain stale data. Native exceptions propagate without synthetic values or rollback, and finally releases the lease so a new genuine callback may accept a new original source. Existing per-tick criticals, hotbar, nearest target and KeepSprint clearance remains in the outer tick, not an inner recursive callback.

This prevents reentrant mixed-source XYZ publication; it does not claim cross-thread atomicity or make runtime animation interpolation authoritative. Java 8/JUnit original-shaped test adapters and installed HostRuntime integration scenarios are source-level evidence, not Mojang binary proof. Require exact V247 Windows/Ubuntu Foundation and genuine pinned original Minecraft 1.8.9 graphical X11 + vanilla server 78-step acceptance plus independent same-SHA rerun. This is cumulative Draft child V246 and does not alter Combat/Render module implementations or main.
