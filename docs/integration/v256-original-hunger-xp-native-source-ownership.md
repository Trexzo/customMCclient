# V256 — Source-owned original hunger and experience snapshots

`Minecraft189HostRuntime.playerHunger` previously read mapped real `foodLevel` and `saturationLevel` in two independent native getter calls and directly published the pair. Likewise, `playerExperience` read four separate genuine original fields: `experienceLevel`, `experienceTotal`, `experienceProgress`, and `experienceBarCap`. Any original getter may synchronously reenter HostRuntime with a different original player or null as the client changes worlds/relogins. The outer call could publish a mixed former/new player state or leave stale values after a genuine getter or state-validator exception.

V256 adds two typed `Minecraft189ExactSourceLease<S>` adapters. Every source callback pins one exact ORIGINAL local-player object through all its mapped getter reads. A same-source nested callback does not create a second original tick; different/null nested source permanently revokes the outer stack. Revalidate immediately after EACH genuine getter, and publish a complete value set only if still owned. On replacement/null original, native getter exception or invalid native food/saturation/XP numbers, clear the full corresponding snapshot; retain the genuine Java exception. Try/finally releases the source lease for a later new native player callback.

Existing source validators are unchanged: food 0–20, saturation finite 0–20, XP level/total nonnegative, progress finite 0–1, bar cap positive. No fabricated FoodStats or XP; no Combat/Render module production changes, no setting/mapping modifications. Distinct hunger and XP native callbacks are independently owned: this does not claim they form a single cross-callback atomic player snapshot. Armor/equipment is intentionally left for a separate audit because its native ItemStack durability getters execute during state publication.

The source-level Java 8/JUnit tests exercise genuine-shaped getters and installed HostRuntime, not a binary Minecraft gameplay certification. Require exact-head Windows/Ubuntu Foundation and pinned Mojang Minecraft 1.8.9 graphical X11 + vanilla dedicated-server 78/78 plus independent same-head 78/78 rerun. Draft child V255; no merge or main changes.
