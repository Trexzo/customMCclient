# V251 — Consolidate four identical exact-reference native source leases

The cumulative V245–V250 original-source hardening introduced four near-identical source-owner implementations: `Minecraft189MovementSnapshotSourceLease` (native onGround/sneaking/sprinting), `Minecraft189PositionHostSourceLease` (native local XYZ), `Minecraft189WorldEntityHostSourceLease` (native loaded World visibility/UUID/XYZ), and `Minecraft189WorldEntityDownstreamSourceLease` (native World Kinds/Combat getter and identity recheck). Each maintained the exact same three-step invariant: one original Java object identity enters, nested same source cannot borrow another tick, and a different or null nested source permanently revokes the outer read until `finally` exits.

V251 consolidates that existing behavior into package-private `Minecraft189ExactSourceLease<S>`. The four prior named adapters remain available as tiny typed subclasses: no HostRuntime call sites, lifecycle policy, mapped native getter, original-world evidence, Combat selection logic, GUI-focus semantics, persistence, or transformer mapping is altered. The generic class uses **reference identity** (`!=`), not `.equals()`, and resets its source/revocation state on the existing exit call. This prevents drift in future owner safety fixes without changing game logic.

26 new deterministic Java 8/JUnit tests verify all four typed source adapters individually: new original admission, same-source reentry, changed-source irreversible revocation, nested null, initial null, and next-tick recovery after a real getter exception. Two further tests prove reference identity even when `.equals()` returns true and isolation between simultaneous independent local position and ground/sprint native ownership stacks. All prior module and actual HostRuntime integration tests from V245–V250 remain unchanged and must pass on both Windows and Ubuntu. This is intentionally a maintenance-only refactor, **not** claimed to resolve in-place loadedEntityList generation reorder or unrelated FOV/UUID native acceptance failures. GUI-aware motion/jump/sprint/rotation leases are deliberately NOT generalized because they have different focus policy and guarded-setter contracts.

Require full exact-head pinned Mojang 1.8.9 graphical X11 plus vanilla dedicated-server 78/78 admission, followed by independent unchanged-SHA original rerun, in addition to exact-head Foundation Windows+Ubuntu. Child Draft PR on V250; historical source/native failures retained, no `main` changes or merge.

V251 now extends the existing genuine official workflow paths with both source-lease implementation and regression-test globs. The existing workflow path-verification script gains two tests enumerating all nine relevant source owners and four representative test classes to prevent recurrence.
